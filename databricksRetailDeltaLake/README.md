# Delta Lake Customer Pipeline

A simple **Delta Lake** project that demonstrates building a retail **customer data pipeline** using **PySpark**. This project covers ingestion, cleaning, incremental updates, and time travel on customer data.

---

## Features

- Ingest raw customer CSV into Delta Lake  
- Clean and transform data using PySpark  
- Query historical data with **time travel**  
- Optimize storage with **compaction** and **vacuum**  

---

## Tech Stack

- Python 3.x  
- PySpark  
- SQL
- **Delta Lake**  
- Databricks Community Edition 

---

## Dataset

- `customers.csv` – sample customer data
